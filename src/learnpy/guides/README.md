# Python 教程

每个 Notebook 聚焦一个可独立运行的主题。

## 语言与数据

- `python_basics.ipynb`：Python 基础
- `data.ipynb`：数据处理
- `concurrency.ipynb`：并发编程

## 工程实践

- `scheduling.ipynb`：APScheduler 任务调度
- `validation.ipynb`：Pydantic 数据校验
- `web_apps.ipynb`：Gradio 与 Streamlit 应用
- `browser.ipynb`：Playwright 浏览器自动化

## 算法练习

- `algorithms.ipynb`：常用算法
- `problems.ipynb`：综合题
- `leetcode_bank.ipynb`：LeetCode 题目
